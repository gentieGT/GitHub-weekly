# 手机访问

## 为什么手机打不开

推送消息里曾经用的是 `http://127.0.0.1:11436/`。`127.0.0.1` 意思是「本机」，在手机上指的是**手机自己**，所以打不开。

必须用电脑的**局域网 IP**，形如 `http://192.168.1.5:11436/`。

## 现在的状态

服务已改为监听 `0.0.0.0`（所有网卡），推送链接自动用局域网地址。

推送时控制台会打印实际使用的地址：

```
推送 2026-11-23（10 个项目）…
链接地址: http://192.168.1.5:11436/?week=2026-11-23
```

## 手机还是打不开怎么办

### 第一步：确认同一个 WiFi

手机和电脑必须连**同一个路由器**。注意别一个连 5G 一个连 2.4G 的不同 SSID（一般同一路由器两个频段互通，但访客网络不互通）。

### 第二步：放行防火墙

防火墙规则需要管理员权限，我加不了，你双击一次：

**双击 `open-phone-access.cmd`**，弹出 UAC 就点「是」。

它会：
1. 给 11436 端口加 TCP 入站放行（专用 + 公用网络）
2. 打印当前局域网地址

### 第三步：排查路由器

如果前两步都做了还打不开，常见两个原因：

| 原因 | 表现 | 解决 |
|---|---|---|
| **AP 隔离** | 手机能连 WiFi 但 ping 不通电脑 | 路由器设置里关掉「AP 隔离」/「客户端隔离」 |
| **访客网络** | 同上 | 别用访客网络，连主网络 |

测试方法：手机浏览器打开 `http://192.168.1.5:11436/`，如果一直转圈超时，基本就是这两个原因。

## 手动查询局域网 IP

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' } |
  Select-Object IPAddress, InterfaceAlias
```

输出里的 `192.168.x.x` 就是手机该用的地址。

## 只想本机用？

```powershell
node server.mjs --host=127.0.0.1
```

这样就只监听本机，手机访问不到（更安全）。

## 安全提醒

服务现在对局域网开放，意味着**同一 WiFi 下的任何设备**都能：

- 查看你的周报
- 提交想法（写到 `inbox/ideas.jsonl`）
- 点 Star（用你本机的 GitHub token）

家里 WiFi 一般没问题，**公共 WiFi（咖啡厅、酒店）建议改回 `--host=127.0.0.1`**。

## 改 IP 后要做什么

如果换了网络（比如换 WiFi 或路由器重新分配 IP），推送链接会失效。重新推一次即可：

```powershell
node tools/push-issue.mjs
```

它会自动用当前的新 IP。

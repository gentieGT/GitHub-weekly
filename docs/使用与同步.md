# 怎么用 / 怎么同步

## 打开周报

**双击桌面上的「GitHub 周热榜」** —— 服务没在跑会自动启动，然后打开浏览器。

或者双击项目里的 `打开周报.cmd`。

地址：http://127.0.0.1:11436

## 它自己会活着

计划任务 `GH-Weekly`（每 5 分钟检查一次）：

- 开机登录后自动启动
- 服务崩了 5 分钟内自动拉起
- 全程无窗口（用 wscript 包装，绕开 Windows Terminal 弹黑框）

查看日志：`watchdog.log`、`watchdog-launch.log`

手动验证：

```powershell
schtasks /run /tn "GH-Weekly"
```

# 改完怎么同步到 GitHub

仓库：https://github.com/gentieGT/GitHub-weekly

## 方法一：双击脚本（推荐）

双击 **`同步到GitHub.cmd`**

它会：
1. 显示你改了什么
2. 问一句提交说明（直接回车用时间戳）
3. 暂存 → 提交 → 推送

## 方法二：命令行

```powershell
cd D:\dsh-workspace\gh-weekly
git add -A
git commit -m "说明你改了什么"
git push
```

## 改完代码要让服务生效

网页改动需要重启服务：

```powershell
# 杀掉旧进程
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -like '*gh-weekly*server.mjs*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }

# 重新启动（或直接双击 打开周报.cmd，它会自动拉起）
node server.mjs
```

# 什么会被提交，什么不会

## 会提交（公开可见）

| 内容 | 说明 |
|---|---|
| 所有代码 | `server.mjs`、`flags.mjs`、`tools/` |
| 项目文档 | `AGENTS.md`、`docs/` 下 5 份 |
| 历史数据 | `data/weekly-*.json`、`data/briefings-*.json` |
| 开关配置 | `config/flags.json`（不含密钥） |
| 任务模板 | `watchdog-task.template.xml`（占位符，不含你的用户名） |

## 不会提交（`.gitignore` 保护）

| 文件 | 为什么 |
|---|---|
| `inbox/ideas.jsonl` | 你提交的私人想法 |
| `inbox/reports.jsonl` | 实践员的反馈（含你的项目信息） |
| `config/wecom.json` | 企业微信 webhook（含密钥） |
| `data/star-cache.json` | 你的 GitHub Star 行为记录 |
| `watchdog-task.xml` | 本机生成版，含真实用户名和路径 |
| `experiments/` | 实践员的临时试验产物 |
| `*.log` | 运行日志 |

> ⚠️ **每次提交前请扫一眼 `git status`**。如果看到上面这些文件出现在待提交列表里，说明 `.gitignore` 被破坏了，先修再提交。

# 企业微信推送（待配置）

推送模块已就绪，只差 webhook 地址。

## 拿到 webhook

1. 打开企业微信
2. 进入任意一个**群聊**（可以自己建一个只有自己的群）
3. 右上角 `...` → **群机器人** → **添加机器人**
4. 起个名字（比如「周报」）
5. 复制 **Webhook 地址**

地址长这样：

```
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx
```

## 配置并测试

```powershell
cd D:\dsh-workspace\gh-weekly
node tools/notify.mjs --set-webhook "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key"
```

脚本会保存配置并立即发一条测试消息。群里收到就说明通了。

## 其他命令

```powershell
node tools/notify.mjs --config        # 看当前配置
node tools/notify.mjs --test          # 发测试消息
node tools/notify.mjs "随便说句话"     # 发文本
```

# 别人 clone 下来怎么跑

```powershell
git clone https://github.com/gentieGT/GitHub-weekly.git
cd GitHub-weekly
node server.mjs
```

零依赖，装了 Node ≥ 18 就能跑。

要开机自启的话，改 `watchdog-task.template.xml` 里两个占位符：

- `PUT_YOUR_USER_HERE` → 你的账户（`whoami` 查）
- `PUT_PROJECT_DIR_HERE` → 项目绝对路径

然后：

```powershell
schtasks /create /tn "GH-Weekly" /xml watchdog-task.xml /f
```

Star 功能需要本机 git 已登录 GitHub（token 从凭据管理器读），没登录也能用，只是 Star 按钮点不了。

# UI 设计

## 整体基调

深色、克制、信息密度高。参照 GitHub 自身配色，让眼睛不累。目标是「扫读」而不是「阅读」——**标题和概括必须一眼能看懂，简报是可选深入**。

## 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#0d1117` | GitHub 深色底 |
| 卡片 | `#161b22` | 比背景略亮，形成层次 |
| 边框 | `#30363d` | 常规分隔 |
| 边框（hover） | `#484f58` | 悬停反馈 |
| 主文字 | `#e6edf3` | 标题 |
| 次文字 | `#c9d1d9` | 正文 |
| 弱文字 | `#8b949e` | 元信息 |
| 强调蓝 | `#58a6ff` | 链接、标签、可借鉴 |
| 相关黄 | `#d29922` | 「与你相关」、实践反馈 |
| 成功绿 | `#3fb950` | 「对你的用处」、提交成功 |
| 危险红 | `#f85149` | 错误提示 |

## 布局

```
┌─────────────────────────────────────────┐
│ GitHub 周热榜 · 2026-11-23              │  26px 粗体
│ 本周新建且 star 增长最快的 10 个项目…    │  13px 弱色
├─────────────────────────────────────────┤  分隔线
│ ┌───┬───────────────────────────┬─────┐ │
│ │ 1 │ repo 名                    │展开 │ │  卡片头（可点整行）
│ │   │ 一句话概括                 │简报 │ │
│ │   │ Python ★15,913 ● 了解即可  │     │ │
│ ├───┴───────────────────────────┴─────┤ │  展开后：
│ │ 为什么火                               │ │
│ │ 简报（150-250字）                      │ │
│ │ ┃ 对你的用处（绿底绿边高亮）           │ │
│ │ #标签 #标签                            │ │
│ │ ┌──────────────────┐ ┌──────┐        │ │
│ │ │ 你的想法…         │ │提交   │        │ │
│ │ └──────────────────┘ └──────┘        │ │
│ └───────────────────────────────────────┘ │
│ … 重复 10 次 …                            │
└─────────────────────────────────────────┘
```

最大宽度 900px 居中，两侧留白。移动端自动收窄（`viewport` 已设）。

## 卡片

| 元素 | 规格 |
|---|---|
| 圆角 | 12px |
| 内边距 | 头部 16px 18px，展开区左 62px（对齐内容，避开排名徽章） |
| 排名徽章 | 30×30，圆角 8px，深灰底，13px 粗体 |
| 标题 | 16px 粗体，可点跳 GitHub |
| 概括 | 14px，`#c9d1d9`，和标题间距 3px |
| 元信息胶囊 | 12px，`#21262d` 底，圆角 20px |
| 展开按钮 | 12px，右侧固定，文字在「展开简报 ▾」「收起 ▴」间切换 |

## 展开区

三段式，每段小标题是 12px 大写灰色，正文 14px：

1. **为什么火** — 常规，无底色
2. **简报** — 常规，无底色
3. **对你的用处** — `#12261a` 绿底 + 左侧 3px 绿边 + 圆角 6px。**这是全页视觉焦点**，因为它是 Kairo 唯一真正关心的部分

标签：`#0d2847` 蓝底，`#58a6ff` 文字，圆角 20px。

## 已提交的想法与反馈

```
┌─ 蓝底蓝边块 ─────────────────┐
│ 11-23 03:14  这个思路能不能… │  13px
│ ┌─ 橙底橙边 ──────────────┐ │
│ │ 🔧 实践反馈              │ │
│ │ 结论：…                  │ │
│ │ （多行，pre-wrap）        │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

- 想法块：`#0d2847` 底 + `#1f6feb` 边，时间戳 11px 蓝色
- 反馈块：`#1c2128` 底 + 左侧 3px `#d29922` 橙边
- 未处理时显示 `⏳ 已收到，等待实践`（灰色 12px）

## 交互

| 动作 | 反馈 |
|---|---|
| 鼠标移到卡片 | 边框变 `#484f58` |
| 点卡片头任意处 | 展开/收起（整行可点，不只是按钮） |
| 点标题链接 | 新标签页打开 GitHub（`rel="noopener"`） |
| 想法为空时提交 | 输入框下方红字「先写点什么」 |
| 提交中 | 按钮禁用，显示「提交中…」 |
| 提交成功 | 绿字「已收到 ✓ 实践员会在这个项目下回复你」，输入框清空，想法即时插入列表 |
| 提交失败 | 红字显示错误码 |

## 已知取舍

- **刷新后卡片全部收起** — 展开状态没持久化。理由：每次看都是新的，收起状态更适合扫读。如果 Kairo 觉得烦，可以加 localStorage 记住
- **无分页/搜索** — 只有 10 条，不需要
- **无深色/浅色切换** — 固定深色，减少决策

## 改样式去哪儿

全部样式在 `server.mjs` 的 `renderPage()` 里，`<style>` 块。按注释找对应区块：

- `:root` — 所有颜色变量
- `.card` / `.head` / `.body` — 卡片结构
- `.sec` / `.sec.hl` — 展开区三段
- `.myideas` / `.report` — 想法与反馈
- `.composer` — 输入区

## M6 · 历史周栏 + Star + 整卡展开（2026-11-24 完成）

**目标**：Kairo 提的三件事——点卡片整卡展开、展开区加 Star 一键点亮、左侧加历史周卡片 + 更多搜索。

| 任务 | 状态 |
|---|---|
| 整卡点击展开/收起（点链接不触发） | ✅ `toggleCard()`，`ev.target.closest('a')` 排除链接 |
| 展开区 Star 按钮 | ✅ 金色点亮，已 star 显示「★ 已 Star」 |
| Star 真正调 GitHub API | ✅ 走 `git credential fill` 取 token（gentieGT，repo scope） |
| Star 状态批量查询 + 缓存 | ✅ `/stars` 端点，5 分钟 TTL |
| 左侧历史周栏（最多 5 周） | ✅ 点击切 `?week=YYYY-MM-DD` |
| 「更多…」搜索面板 | ✅ 关键词（含简报正文）+ 月份筛选 |
| 仓库失效的降级提示 | ✅ 显示「仓库已不存在」，按钮置灰 |

**验证**：端到端脚本 `tools/e2e-star.mjs` 实测——star → GitHub 返回 204（真点亮）→ 回滚 → 返回 404（真取消），全通过。

**新增文件**：`tools/star.mjs`（token + star/unstar + 缓存）、`tools/check-token.mjs`、`tools/verify-repos.mjs`、`tools/e2e-star.mjs`

**新增路由**：`POST /star`、`GET /stars`、`GET /search`、`GET /?week=`

**数据发现**：首期 10 个仓库里 2 个已被删除/改名（Leonida、blender-ai-mcp-addon）。
